## Como eu trabalho

- **A IA interpreta, o código decide.** Decisão que custa dinheiro ou envolve risco fica com regra e com uma pessoa.
- **Medir antes de afirmar.** Todo projeto tem um gabarito, um número e uma lista do que ainda falha.
- **Corrigir pelo erro.** Quando a IA erra, eu olho o padrão e escrevo a regra que faltava, em vez de reescrever tudo.
